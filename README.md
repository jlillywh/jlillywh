## About
I am a civil engineer specializing in water resources modeling, hydraulics, and hydrology. I integrate engineering and software by developing web-based dynamic visualization tools and "Digital Twin" technology to solve complex water management challenges.

I founded **Lillywhite Water Solutions LLC** to provide independent consulting and custom software solutions for the water industry.

## Flagship Products

### [R-THYM](https://www.r-thym.com/)
A web-native digital twin tool designed for real-time hydraulic modeling. It allows for simulating flow networks directly in the browser, bridging the gap between complex engineering simulations and interactive, actionable web visualizations.

### [STREAM-1D](https://www.stream1d.com/)
A high-performance 1D open-channel hydraulics engine and web dashboard. Written in Rust and compiled to WebAssembly (WASM), it solves steady and unsteady flow routing (1D Saint-Venant equations) instantly. Features zero-install execution in the browser, native Python bindings for automated batch processing, and live 60-FPS UI updates for WSEL and EGL profiles.

### [IAMDD](https://lillywhitewater.com/products/iamdd/)
The Integrated Agricultural and Municipal Demand-Delivery framework. This tool provides a robust, web-based system for managing water rights, specifically tailored for irrigation and municipal demand scenarios.
